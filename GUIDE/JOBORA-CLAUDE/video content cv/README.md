# video content cv/

Carpeta de trabajo para el flujo **CV Video Content ES** (nicho `video-content-es`):
CV y candidaturas como **Course Creator / creador de píldoras y videotutoriales**
en español (grabar cursos, escribir cursos, crear laboratorios, crear ejercicios,
revisar contenido).

Es distinto de `formador cv/` (formador FUNDAE / aula). Aquí el foco es
**producción de contenido** e-learning, no necesariamente impartir clase.

## Contenido

- Fuente de verdad: `fullstack cv/Argenis_Gonzalez_CV_2026.md` (nunca se edita).
- `companies-cache.json` — empresas ya investigadas.
- `output/` — generado por `/cv-job-search-video-content`:
  - `CV_Video_Pildoras_ATS_<fecha>.md`
  - `<empresa>/mensaje-solicitud.md`
  - `ats-informe.md`
  - `resumen.md`

## Cómo usarla

Ejecuta `/cv-job-search-video-content` en Cursor
(`.cursor/commands/cv-job-search-video-content.md`).

Skill: `.cursor/skills/cv-video-content-es/`.

**Gate:** solo ofertas/contenido en **español** (España por defecto).

**Importante:** todo son borradores. El agente no envía solicitudes ni rellena
formularios por ti.
