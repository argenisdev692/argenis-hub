# Platforms + CapCut — Social Media Studio

## Platform specs

| Platform | Length | Structure | Hashtags | Image aspect |
|----------|--------|-----------|----------|--------------|
| LinkedIn | ~1000–1300 chars | Hook → 3–5 insight blocks → CTA (SAAEEF) | 3–5 niche | 16:9 |
| Twitter/X | ≤280 single **or** thread `[1/N]` | Bold hook → insight → CTA | 1–2 | 16:9 |
| Instagram | 400–600 caption | Visual hook → story → community CTA + CapCut | 5–8 | 1:1 (or 4:5 feed) |
| Facebook | 400–600 | Conversational hook → story → community CTA | 2–3 | 16:9 |
| TikTok | 1–2 line caption (≠ LinkedIn) | Caption + CapCut package | 5–7 mix niche + discovery | 9:16 thumb |

First LinkedIn block (2 lines max) must work before "…see more".

## Funnel → CapCut duration

| Stage | `target_duration_seconds` | CTA vibe |
|-------|---------------------------|----------|
| TOFU | 15 | save / follow / one-word comment |
| MOFU | 21–30 | discuss / resource |
| BOFU | 15–20 | message / book on argenis.dev |

`creative_style` MUST be `ugc_native` (phone-camera energy, captions always,
no corporate bumper). Cuts every 2–4s. On-screen text every scene (3–6 words).
VO first person. One message, one CTA.

`sound_suggestion` = audio **type** + CapCut/TikTok search term — never invent
a specific track title.

|------|--------|----------------|-----------|---------------|

Also deliver: clean VO script (continuous), numbered shot list, TikTok caption,
TikTok hashtags.

## Image routes (prompts in English)

- **A** — title (2–5 words) + emblem/icon (default news/hooks)
- **B** — abstract concept, **no text** (overlay later)
- **C** — roadmap / steps → put 3–6 short labels in `svg_steps` (SVG preferred;
  do not bake labels into DALL·E visual)

Brand palette in every prompt: deep navy `#0B1120`, electric purple `#6366F1`,
dark editorial, minimalist, no watermark, no long paragraphs on image.
